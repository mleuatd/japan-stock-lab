# japan-stock-lab

日本株の過去株価データ収集・分析・300万円の仮想売買研究。**実際の証券注文は行いません。**

## 初期設定
1. J-Quantsで無料アカウントを作成し、APIキーを発行する。
2. GitHub `Settings → Secrets and variables → Actions` に `JQUANTS_API_KEY` として登録する（キーをファイルに書かない）。
3. `Actions → Collect delayed J-Quants history → Run workflow` で初回実行する。
4. 成功すると過去の日足を日付単位の圧縮CSVで保存します。既存取得分をスキップして次の実行時に続けます。

## 保存について
出力: `archive/daily/YYYY/MM/YYYY-MM-DD.csv.gz`。公開リポジトリにはAPIデータをコミットしません。Actions cache・artifactは**一時保存**であり永続保管ではありません。重要な履歴は、利用規約を確認した上で別途非公開の保存先にバックアップしてください。無料プランの12週間遅延に注意してください。

## 注意点
Secretsの存在はワークフロー実行時に値を表示せず検証できます。全銘柄の完全な価格履歴を保証するものではありません。欠損や取引停止日・株式分割等の検証はバックテスト前に別途必要です。自動実行は平日（GitHub側の遅延あり）で、発注機能はありません。

## 継続収集・保存・検索（2026-10-08 更新）

- 平日20:27 JSTのスケジュールと手動起動で、1回最大80平日を要求。既存日付のCSVが存在する場合はAPIへ再問い合わせしません。API提供日が12週間遅延している点に注意。
- **恒久保存は別途設定必須。** GitHub Actions cache/artifactだけでは消失リスクがあります。GitHubに**非公開リポジトリ**（例: `mleuatd/japan-stock-private-archive`、デフォルトブランチ `main`、初期READMEあり）を用意し、元の公開リポジトリの Actions **Variables** に `PRIVATE_ARCHIVE_REPO=owner/private-repo`、**Secrets** にその非公開リポジトリにのみ `Contents: Read and write` 権限のある `PRIVATE_ARCHIVE_TOKEN` を設定してください。GitHub Actionsが取得前に非公開バックアップから復元、収集検証後に未保存の日付ファイルだけを非公開リポジトリに保存します。トークンをREADMEやチャットに貼らないでください。
- 非公開バックアップが未設定の間、古いキャッシュが消えると再取得を完全には防止できません。非公開リポジトリもストレージ上限・データ利用規約の制約があり、大容量化した際はprivate object storageへの移行を検討します。
- ブラウザUI：[`docs/index.html`](docs/index.html)。CSV.gzを端末内で取り込み、ブラウザー保存、日付／銘柄コード／出来高／並び順の変更、URLパラメータのコピーができます。**GitHub Pages公開設定は未構成**なので、現時点で稼働URLはありません。URLだけでは非公開の元データは配信されず、同じ端末に取り込み済みのデータが必要です。
- ブラウザ検索の現状は銘柄コード、終値、出来高、単純な前日比に限ります。市場分類、企業名、優待、財務、5日連続TOP30、分割調整、仮想売買は今後の機能です。
- APIライセンスの可否を確認するまで生の株価データや再構成可能なランキングを公開サイトへ配信しないこと。全て自己利用を前提とします。

詳細な状況・次の実装対象は [docs/HANDOFF.md](docs/HANDOFF.md) に記録しています。
