# 株価の「下がるリスク」を分析する v2

## 修正の理由

以前の分類は16種（うち比較用BASEが1つ）。株価形状の代表例として不足していた。パイロット7846の HIGH20 + SMA_BULL 該当は数式上の一致にすぎず、チャート全体の類似や予測精度の実証ではなかった。先に表示した「30日後2,120円」は確かな予測値ではなく、過去の観測事例を現在価格に換算した中央値である。

## 主眼を上昇から下落へ変更

各パターンについて翌1～30取引営業日の各日ごとに次の数字を出す。

- 基準日終値よりその日の終値が低い比率、件数、Wilsonの参考区間
- その日の終値が基準日より3%・5%・10%以上低い比率
- 基準日翌日からその日までに、日中安値が3%・5%・10%以上落ちた比率（終値が回復していても計上）
- 個別の観測母数、欠損・まだ未来が存在しない件数、上昇と横ばい件数
- 過去比較用のBASE、全銘柄の基準群

日足の安値は、実際の損切り注文が約定できる値段ではない。ギャップや取引停止・値幅制限などは別途検証が必要。

## 120種類の実条件 + 基準1種 = 121種

| 分野 | 条件数 | 内容 |
|---|---:|---|
| 1/3/5/10/20日リターン閾値 | 40 | 上下それぞれ1/3/5/10%以上 |
| 連続上昇・下落 | 12 | 2～7営業日 |
| 高値・安値更新 | 6 | 過去5/10/20営業日 |
| 移動平均の方向・クロス | 10 | 3/5/10/20日平均の上下と5対20日のクロス |
| レンジ位置、下落幅・反発幅 | 10 | レンジ上位/下位20/40%、高値比−5/10/20%、安値比+5/10/20% |
| ボラティリティ | 9 | 5/10/20日変動の強度 |
| 出来高異常 | 8 | 直前5日平均の1.5/2/3倍、半減 |
| ローソク足 | 13 | 大陰/陽線、ヒゲ、ギャップ、包み足、十字、終値位置など |
| 固定した複合条件 | 12 | 高値×出来高、移動平均×連続下落など |
| **比較基準** | **1** | BASE |
| **合計** | **121** | 当てはまらない条件を無理に付与しない |

これらは検証前に決めた観測条件であり、**121種類の有効な予測パターンを発見したわけではない**。条件を増やすほど偶然の「好成績」も見つかりやすいため、特定の上位条件を勝手に購入推奨へ昇格させない。

## GitHub・Neonへの実装

- downside_pattern_research.py：21営業日までで条件判定、未来30日で実際の下落割合・一時的な急落割合を集計
- downside_pattern_storage.py：秘密株価をコピーせず、集計行だけデータベースへ保存
- sql/008_downside_patterns_v2.sql：従来のV1を破壊せず、独立したV2テーブルと表示ビューを新設
- downside_pattern_30day：day01～day30は「その日の終値が基準日より下落していた割合（%）」
- .github/workflows/downside-patterns-v2.yml：GitHub Actionsから秘密Neonを読む実集計処理
- tests/test_downside_pattern_research.py：不足データ、日中急落、未来先読み、上場注意などの回帰テスト

## データが不十分なとき

200事例以上、かつ50銘柄以上の観測がない条件は INSUFFICIENT_EVIDENCE とし、数値を購入判断に使わない。過去統計がこの基準を満たしても、将来の下落確率が正しく較正されたわけではない。

同一銘柄・同一条件が連続しても30営業日間は二重計上しない。訓練と検証を時系列で分け、未来の情報が条件判定に入らないようにする。途中1日でも低値が欠損すれば「一時的な急落」の母集団からは除外し、欠損を隠さず報告する。

全市場の上場廃止・監理・整理情報は未網羅。株式分割に伴う価格調整も完全検証前なので、結果は HISTORICAL DESCRIPTIVE ONLY（過去記述統計）であり、現在の株を確実に予測したと表示しない。

## SQL例

```sql
SELECT pattern_code, pattern_name, day01, day05, day10, day20, day30
FROM downside_pattern_30day
WHERE segment='holdout'
ORDER BY day20 DESC NULLS LAST;
```

```sql
SELECT pattern_code, horizon, observed_count, unique_symbols,
       down_pct, close_loss5_pct, touch_loss5_pct,
       path_unknown_count, evidence_state
FROM downside_pattern_stat_v2
WHERE segment='holdout' AND horizon IN (1,5,10,20,30);
```
