# マイナスを避けるための危険パターン消去法

## 目的と流れ

- 上がりそうな株を探すのではなく、過去に損失に結びつきやすいことが別期間でも確認されたパターンに一致する株を除外。
- 横ばいは許容し、少しのプラスでもよいが、購入でマイナスにならない保証はできない。
- 120種類の観測条件（+BASE）の全てを危険扱いしない。V2統計の学習期間で、20営業日後の終値下落、終値5%以上下落、途中安値5%以上下落が比較基準より悪化する条件を調べる。
- 学習期間500標本・100銘柄以上、検証期間250標本・100銘柄以上、欠損率3%以下を要求。厳しいWilson区間・悪化幅による選別後、検証期間にも悪化が現れる条件を暫定的に「危険パターン」とする。120通りの多重検定、企業行動や相場の共変動は完全検証していない。
- 今日の21営業日のOHLCVが揃った銘柄について、危険条件にどれか1つ当てはまれば除外。当てはまらない株を研究候補として一覧化。
- 価格が古い、21営業日に穴がある、ローソク足が不正、既知のJPX警告がある、下落パターンの検証が完成していない等の場合は「該当なし」扱いをせず、保留または除外。
- 危険パターン該当ゼロは損しない証明ではない。すべての表示は RESEARCH_WATCHLIST_ONLY。実買いの承認は NOT_APPROVED / 0 件で固定。

## 実装

- risk_veto_daily_screen.py: 各パターンの学習・検証統計から危険条件を選び、日足が新しい場合だけ銘柄の除外・調査候補状態を判定。
- sql/009_risk_veto_watchlist.sql: Neon専用の判定日時・候補/除外数の履歴と、銘柄の状態・危険パターンを保存。株価そのものは複製しない。
- .github/workflows/risk-veto-daily.yml: 平日の23:55 JSTに1回実行し、日足の新鮮さを検査。休日やGitHub Actions遅延はあり得る。
- Neonビュー risk_veto_latest_watch: 最新日付の調査候補コードの一覧。公開GitHubのログにコード/生の株価を出さない。

## 表示イメージ（架空）

A社: 危険な高変動/安値更新パターン -> 除外
B社: 20日平均下向きと連続下落 -> 除外
C社: 検証済み危険パターンには該当しない -> 調査候補（購入許可ではない）
D社: データ欠損 / 上場状況不明 -> 判定保留

## 残る障害

**現在のNeonは2026年7月17日までのデータ**で、2026年10月10日時点の最新候補として扱えない。情報の遅延を検知して候補を出さないようにしたが、リアルタイム日足の合法的・安定したソースが必要。また過去の除外ゼロ銘柄の実際の損失率（見逃した損失）を独立データで検証する工程が未完了。全JPX上場廃止・監理などの網羅も必要。
