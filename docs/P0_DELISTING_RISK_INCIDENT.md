# P0: 上場廃止予定・監理・特別注意銘柄を購入する重大欠陥

## 確認できた事実

2026年7月17日を終点とする旧実験は、実際に約定を再現した仮想口座の最終保有4銘柄のうち1銘柄の終値がなく、正式な損益を確定できない。以前の「参考時価108,423.60円」は**最後の観測値を利用した非売買可能な参考値**であり、実現可能な清算額ではない。失敗した元実験を有効な「-39万円の成績」と認定しない。

同日株価が存在しないことを理由に、未来情報を使って「以前から買えなかった」と判断してもいけない。必要なのは**その当日までに公式に発表済みの市場区分・警告・上場廃止日**である。

## 今回の部分修正

1. `jpx_market_risk.py` に上記の証拠付きで「公表日」を記録。公表日の**引け後**に新規買いシグナルを停止し、翌取引日の始値以降は買い注文を阻止する。公表当日の始値をさかのぼって止めない。
2. 旧全市場バックテスト、単純バックテスト、戦略組み合わせ比較、損切り利益確定検証、夜間の仮想買い候補に共通チェックを追加。
3. 既存保有株に公表済み警告があれば翌取引日の**売却要求**を出す。取引停止、売り注文不成立、株価なしなら架空の約定や架空の換金をしない。
4. 企業行動・TOB・株式併合、現物株売却の法的可能性は別に扱う。警告を受けた日の株価で必ず売れると仮定しない。
5. 訓練期間の銘柄イベントも「その時点まで公表済み」の状態で除外し、将来の上場廃止結果を過去に流用しない。

## まだ安全と断言できない重大な不足

**このリストは全市場の履歴ではありません。これだけで「上場廃止銘柄を絶対買わない」とは保証できません。**

- 市場の全銘柄に対するJPX指定・解除・整理・上場廃止・上場維持情報を、根拠URL・**公開日**・発効日・解除日とともに継続取得して検証する（ライセンス順守）。
- 上場廃止後の現金対価や株式併合を正しくモデル化し、保有株の実際の権利・売却可能性を証拠付きで監査する。
- 既に失敗した古いmainの実行結果を再掲するのではなく、上記の検証が揃ってから、**新しいコード**で再実行し差分を確認する。比較には元のパラメータ・日足データの同一性が必要。
- 速報の参考時価は旧戦略の成績であり、新規対策の有効性・利益を裏付けない。企業行動台帳が完成するまで結果は暫定扱い。

## 調査を優先すべき問い

- 旧実験で無価値または上場廃止になったと推定される銘柄は実際に**いつ買ったのか**。公表前か後か。
- 何日間売却要求を出していたか。最終の株数、権利関係、上場廃止後の措置、換金可否。
- 安全フィルター後に買い候補の何件が変わり、実際の損益がどう変わったか。
