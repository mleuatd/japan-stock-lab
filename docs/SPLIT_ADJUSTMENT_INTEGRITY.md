# J-Quants株式分割・併合の補正監査（2026-10-10）

## 何を調査したか

Neon Freeの `daily_bar` 全1,914,081行・4,714銘柄（2024-10-08～2026-07-17）を調査。

- `adjustment_factor <> 1` が記録された権利落ち日：**453件／440銘柄**（銘柄比9.33%）
- 連続する前日と当日の調整済み株価を照合できた：**441件／428銘柄**、全件整合（最大の丸め誤差0.228%、監査許容差0.5%）
- 前日の調整済み株価または権利落ち日の値がなく検証不能：**12件／12銘柄**。これらは全履歴から除外。
- 調整係数が1なのに調整済み/生株価の比が突然変わった例：**0件**（判定差0.5%）
- 分割日をまたぐ441件の絶対前日比の平均：生株価約95.92%、調整済み約3.07%。大部分の見かけ上の極端な暴落・暴騰が取り除かれる。
- `adjusted_close <> close_price` のある500銘柄は「分割済み500銘柄」という意味ではない。調整率が全観測期間で一定の銘柄なども含まれる。

## どう補正・除外するか

J-Quantsの `AdjustmentFactor` は分割・併合時の権利落ち日に記録される。たとえば1株を2株に分割すると当日の `AdjFactor=0.5`。既存Neonには**分割調整済み終値 `adjusted_close` がすでに保存**されているため、有料データの追加契約や同じ約190万行のAPI取り直しは不要。

前日と当日の `adjusted_close/close_price` の比の変化が、当日の `adjustment_factor` と一致するか検査する。見積りや実損益は、既存の `downside_pattern_research.adjusted` により、同一日の生OHLCに `adjusted_close/close_price` を掛けて同一株式数基準で比較する。株価の生データだけを分割日をまたいで比較しない。調整済みの連続性を証明できない銘柄は、当日のみでなくすべての該当学習・検証から除外。

- Neonの `split_adjustment_integrity_events`：権利落ち日・不審な係数変更の監査状態
- Neonの `split_adjustment_blocklist`：検証から除外する12銘柄のみ（新たな欠損・不整合が発生したら自動で増える）
- Neonの `split_adjustment_integrity_summary`：件数の追跡
- `split_adjustment_guard.inspect_guard`：照合結果が欠損・矛盾する場合は**学習全体を停止**する。少数の未検証銘柄のみ学習データから取り除く。
- `downside_pattern_research.from_neon`、`risk_veto_union_audit.from_neon`、`dynamic_exit_research.from_neon`、`risk_veto_daily_screen.retrieve_current`：監査済みグループを含め、未検証の12銘柄を除外。

学習パターンの新しい結果は `jquants-split-guard-v1` を研究run keyに入れ、以前の監査前の結果と混在させない。union veto / dynamic exitも別run。学習（約14分）が成功した後、別の検証ワークフローが順次走るようにする。失敗したら結果未認証とし、購入承認に用いない。

## 限界と次の問題

分割・併合 **のみ** データの整合性を確認。株式移転・合併・上場廃止・TOB・配当・株主権利や実株数に紐づく約定・株式併合端株精算等は未検証。利益確定と損切りの計算は調整後の仮想株価に基づき、手数料・税金・実際の注文約定や取得株数の変化を完璧に復元するものではない。全額損失ゼロを保証しない。

**現段階は研究専用 `NOT_APPROVED`**。日次の直近データが2026-07-17のままのため、今の購入候補への承認は不可。元株価データ・個別銘柄の価格・DB接続情報はGitHubへ公開しない。
