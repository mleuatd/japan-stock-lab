# 保有1～30営業日で動的に損切り・利益確定する研究（v1）

## 目的

「買うときに危険な銘柄を避ける」だけではなく、実際に買った**後**、毎営業日ごとの終値・収益率・直近の下落連続日数を見て、翌営業日の寄り付きで仮想売却を決める。**30営業日以内の正味損失発生率を最優先に低くしながら、正味平均利益も維持・改善する**。買い候補が不適切な場合は無理に選ばず、実注文は出さない。

研究用の最大保有期間は、買付を1営業日目とした**30営業日目の始値での売却**。通常の「30日目終値」ではないのは、未来の終値を見てからその終値で売れたことにしないため。

## 既存との違い

- `chart_bracket.py`：固定損切り・固定利確の価格に日中ヒットした場合の仮想取引。日足内で約定順序の曖昧性あり。
- `dynamic_exit_research.py`：**毎営業日の終値時点で判定し、翌営業日の始値で決済**。前日の終値を見た後にその日の終値で取引することは禁止。逆指値注文を置いていた想定ではないので、当日の日中急落を損切り前に回避する仕組みではない。翌営業日寄りのギャップ損失はその価格で記録する。実市場の寄り付き約定や流動性を保証するものではない。

## 比較対象23条件（固定・事前定義）

- HOLD30：途中で売らず30日目の寄り付きで決済（比較基準）
- DAY05/10/20：固定日経過後、翌日の寄り付きで決済
- STOP_CLOSE1/2/3/5：買値からの終値損失が指定%に達したら、翌日の寄り付きで損切り
- TARGET_CLOSE2/5/10：買値から指定%上昇した終値を観測したら、翌日の寄り付きで利益確定
- TRAIL_CLOSE2/3/5：保有後終値の最高値から指定%下落したら翌寄り付きで利益確定・損切り
- PATTERN_TWO_RED：買付後に2営業日連続で終値下落→翌寄り付き決済
- PATTERN_DOWN3：前日終値比3%以上の下落→翌寄り付き決済
- PATTERN_MA_BEAR：5日平均終値が20日平均終値を下回れば翌寄り付き決済
- STOP{2/3/5}_TARGET{3/5}：損切りと利益確定を合わせた6条件（同じ日の判定は損切り優先）

**DAY05の売却は6日目始値**。日中に達した損切りラインで執行したとする架空の計算は行わない。往復の仮想手数料は買い0.1%、売り0.1%。税金・スプレッド・発注失敗・配当の会計は未反映。

## 学習・検証区分

元のV2学習期間を2026-01-30以前で固定し、価格履歴の2025-07-01付近で TRAIN_A と TRAIN_B に分ける。30日満期の対象が次の区分にまたがらないよう、境界から30市場営業日を引いた範囲だけで各区分を評価。未知期間候補は2026-02-02～2026-07-17の履歴だが、ここは別件ですでに分析済みなので真の未観測検証ではなく**回顧的テスト**と表示する。

同じ銘柄のシグナルは原則30営業日以上空けて数える。未検証のV2危険条件34種による除外後の **SURVIVOR** を、TRAIN_A と TRAIN_B の双方で HOLD30 と**同一シグナルのペア比較**。各区分400件以上で、損失率改善の保守的下限がプラス、-5%以上の損失件数が悪化しない、平均損益が悪化しない、不明な評価が5%以下の場合のみ訓練上の候補とする。条件に合うルールがなければ自動で `NO_TRAIN_VALIDATED_EXIT_POLICY` になり、推薦しない。

比較結果は別々に「損失に転じるのを防いだ件数」「逆に損失に転じさせた件数」「各戦略がプラスになる割合」「平均正味損益」「-5%負け」「何営業日目に売却したか」まで記録する。独立性の低いイベントや約定仮定による過大評価の可能性があるため、信頼区間は確定的な将来性能を意味しない。

## データ完全性

保有中の各営業日にOHLCV・調整後株価の欠損や無効値があれば UNKNOWN とする。売れる寄り付きや出来高のない日を、希望価格で売れたことにしない。上場廃止・株式分割などの監査は未完のまま。価格データは非公開Neonからメモリへ読み出し、**GitHubの公開リポジトリに個別価格・個別売買は一切書き込まない**。Neonには集計のみ保存。

## 非公開集計照会

```sql
SELECT segment,cohort,policy,events,observed,unknown,
       negative_pct,positive_pct,mean_net_pct,
       paired_any_loss_improvement_pp,paired_mean_net_improvement_pp
FROM dynamic_exit_30day_comparison
WHERE run_key=(SELECT run_key FROM dynamic_exit_run ORDER BY created_at DESC LIMIT 1)
  AND cohort='SURVIVOR'
  AND policy IN ('HOLD30',(SELECT selected_policy FROM dynamic_exit_run ORDER BY created_at DESC LIMIT 1))
ORDER BY segment,policy;
```

`dynamic_exit_day`：方策・銘柄群・区分ごとの「売却営業日」分布。出力は特定の証券口座に対する売買指示ではありません。

**注意**：これは現時点の価格の鮮度・企業行動が確認されるまで `NOT_APPROVED`。過去データの中に有効な損切りルールが存在したとしても、将来の損失回避を保証しません。
