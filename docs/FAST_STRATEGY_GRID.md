# 日次の頻繁な現物売買・高速バックテスト (2026-10-10)

## 今回の修正
前回の検証は買い条件40種類の選択に偏り、売りは単純な保有期間5営業日固定で、ユーザー意図と異なっていた。新規 `fast_strategy_grid.py` と `.github/workflows/fast-strategy-grid.yml` を追加。

- 夜に一度だけ終値時点の情報で買い・売り判断し、翌営業日の**始値**に仮約定。
- **現物のみ・空売り禁止・先物禁止・信用取引禁止**、初期資金50万円。売りは保有銘柄のみ、買いは現金のみ。
- 買い5種類：5日下落後反発、上昇モメンタム、20日ブレイクアウト×出来高、下落後反転、出来高急増。
- 売り5種類：当日下落転換、短期移動平均の弱化、1営業日後、3営業日後、5営業日後（夜判定なので翌朝約定）。
- **5×5＝25通り**を試し、売り判断も含めた評価額とドローダウンを比較。
- 非公開Neonの株価を**一回だけ取得**し、前日比・5日/20日騰落率・出来高倍率・移動平均関係を**一回だけ算出**。以後ルールごとに同じ指標を参照して高速化。
- 2026-01-30までを訓練・内部検証に使い、2026-02-02〜保存最新日の期間は外部テスト。未来のテスト期間を条件の選択に利用しない。
- 訓練で評価がマイナスのものしか見つからない場合、無理に買う戦略を採用せず「ルールなし」とする。
- データの最新日は無料J-Quantsの取得可能範囲まで。**現在の10月の相場には適用できない。**

## 現在の制約
試算は初期段階。日々発注しないといけない訳ではなく、条件を満たした場合のみ発注。株式分割、売買停止、配当、スリッページ、実際の始値の約定可否や税金・流動性の影響が未反映。分割調整済み終値で信号を作りながら非調整始値で売買しているため、**実際の収益率として信頼するには企業行動の整合処理が必要**。
現行エンジンでは一度に1銘柄全量売買、同銘柄を日中に何度も繰り返し売買することはない（夜一回判断の制約）。
