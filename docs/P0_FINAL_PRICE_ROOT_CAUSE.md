この224件が旧バックテストの保有ポジションと一致するかは未判明。最近14日間のみ出現し最終日には存在しない銘柄もあるため、現在のユニバース全体の状態を最終日の収録行だけで代替してはいけない。

## 解決条件
1. 最新バックテストの保有銘柄と欠損の突合（公開ログでは銘柄を伏せる）。
2. 当該銘柄の取引停止、上場廃止、株式分割、換金履歴、同日約定可能価格を根拠資料により確認。
3. 確実な価格を取得できない場合は正式な最終資産を **UNKNOWN** のままにして `BLOCKED_EXTERNAL_DATA` と判定。評価可能な別ユニバースでの実験は元の全市場実験と区別。
4. 最後に観測された終値は参考シナリオでしかない。正確な利益へ昇格させない。

検査SQLを `final_session_preflight.py` に組み込み、企業行動を補完するデータを捏造しない。P0-1 はまだ未解決。
