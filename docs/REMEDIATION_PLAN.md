## 最優先3障害の実施手順（2026-10-10 決定）

**進捗を増やす条件**：コードの行数、PR件数、単体テスト件数ではなく、実データに基づいてP0をひとつ以上クローズできるか、あるいは「外部データなしでは解決不可」を実証して代替検証範囲を採用できたかで判断する。

### P0-1：最終総資産の評価不能（Issue #3）
1. 以前のrun 37992284803はコードが古く、実保有の欠損原因を報告していない。現行コードの `valuation_diagnostics` を用いて現実の保有銘柄について発生有無を確認する。軽いNeon最終日監査で224銘柄の価格欠損を確認したが、保有銘柄が含まれるか未確定。
2. 各ポジションの最終観測日、最終日保有株数、終値欠損理由を**非公開の実行環境だけで**突合。銘柄別情報は公開Actionsログへ出さない。
3. 分岐A：公的な同日終値が得られる→原レコードを検証済みソースから補完し、同一日・株数・評価額を再計算。
4. 分岐B：取引停止・上場廃止・合併・交換等→企業行動と換金日を確認して処理。確認できないときは正式な最終時価を「不明」に維持。
5. 分岐C：データ取得が不可能→欠損銘柄を隠して全市場利益を主張せず、**検証可能な銘柄・期間に条件を固定した別実験**として再学習・再検証。元の全市場実験と別物である旨を記録。
6. 参考用の直近終値評価は**未検証の参考シナリオ**でありP0-1の完了扱いにしない。
7. 完了：残存保有の全銘柄について確かな最終時価と処分済みの資金移動が再現され、現金＋保有時価が元帳と一致。満たせなければBLOCKED_EXTERNAL_DATAへ分類して代替実験へ移る。

### P0-2：企業行動・配当による会計不整合（Issue #2）
1. `adjustment_factor != 1`の453行は「453回の分割」とは断定しない。イベントの種類、発効日、倍率、併合時端株の現金処理、配当権利基準日、実際の支払日を裏付けるソースを分けて収集する。
2. 未調整始値で売買、調整後終値でシグナルという混合処理の利用範囲と売買日を特定。実際に保有した銘柄から先に検証。
3. 各イベントを保有株数・取得原価・評価額・配当権利に適用し、独立会計表で一致を確認。過去の約定価格・数量を将来の分割情報から改変して先読みしてはいけない。
4. 必要な履歴が無料で手に入らないケースは**未検証**とし、完全な損益を断定しない。企業行動が存在しないことまで検証できる銘柄・期間に限定して別実験を作る。
5. 完了：対象期間の全保有・全約定イベントの企業行動が監査可能な出典と整合し、配当・税金・手数料込の会計恒等式に誤差がない。

### P0-3：約定可能性と生存者バイアス（Issue #3）
1. 取引できないセッションで売買を成立させず、未約定注文を維持する。
2. 市場の制限値幅、寄付の売買停止、出来高、上場廃止、最低単元、現金制約を検証。日足のみでは寄付に自分の注文が約定できたことを証明できない場合がある。
3. 実約定の確実性が証明できない場合、価格/スリッページ別の複数シナリオ、または保守的な注文数量制約として表示し、単一の「正確な利益」としない。
4. 完了：先読みなし、100株単位、信用なし、マイナス現金なしを維持し、取引不可日は注文が成立しない。外部データなしでは証明不能な約定は未検証と表示。
