# 複数パターンを同時に満たす銘柄の翌1～30営業日シナリオ

## 何を出すか

**その銘柄の本日までの21営業日のチャートから、どの登録パターンに該当するかを自動判定し、同時に満たした過去事例だけを抽出し、翌1～30営業日後の上昇割合・下落割合・株価の中央値・四分位を現在価格に投影する。** 将来の値動きは未知なので「予測参考シナリオ」であり、実際に約定できる購入・売却指値や勝てる確率ではない。

16種類の単独パターンの集計結果（`pattern_forward_stat`）を単純平均しても、2つを同時に満たしたケースの統計にはならない。**同時成立履歴の母集団を直接再抽出**する専用クエリを用いる。

## 2026年10月9日のパイロット（7846）の例

- 現在価格（10/9終値）：2,173.5円。
- 過去の有効取引日21日の調整後終値・出来高を参照。20日高値を更新（HIGH20）、5日SMAが20日SMAを上回る（SMA_BULL）。前日までの20営業日の最高終値2,155.5円を上抜けた。連続3営業日上昇ではない。
- 過去の当該2条件同時成立、かつ2026/02/02から2026/07/17に**参照チャートの長さとその後の実測株価が確認できた**事例を集計。
- 過去の上昇割合：翌1日 45.06%（12,232件）、5日 46.75%（10,800件）、10日 48.27%（10,271件）、20日 40.57%（9,100件）、30日 37.56%（8,213件）。
- 過去事例の中央値を現在価格に投影した目安：翌1日 約2,172円、5日 約2,169円、10日 約2,171円、20日 約2,141円、30日 約2,120円。
- 標本数が減るのは、必要な未来営業日がまだ収録されていない事例、または未来株価が欠落した事例があるため。上昇割合の分母には観測済みだけを使い、観測不能を敗北と判定しない。
- 上場廃止・企業行動・生存者バイアスは完了検証されていない。日足の調整後終値は価格推移の参考であって、当日終値で実際に購入できることを意味しない。
- 次の実際の売買営業日は祝日のため2026/10/13（火）。実データの株価を将来日に挿入する機能はない。

## コード

`joint_pattern_forecast.py` が一般化した実装。入力が最新21営業日分あれば `pattern_forward_stats.detect()` で16種類から該当パターンを特定し、その全条件をANDで満たした過去事例だけをNeon `daily_bar` から照合する。既存の30日集計表との混同を避けるため、そのコードをそのまま統計処理する。

SQLは内部で定義したパターンだけを使う。取引営業日の連続性はグローバル市場日付インデックスで確認。保有・売却注文は実行しない。重複期間の間引きは1銘柄につき30営業日単位の固定バケットから最も早い事例1件を選ぶ近似で、統計的独立性を保証するものではない。

### 実行例：最新21営業日分から自動抽出

秘密ファイル `private-current-21.json`（公開GitHubにコミット禁止）の内容：

```json
[
 {"date":"2026-09-08","adjusted_close":2027,"volume":289300},
 {"date":"2026-09-09","adjusted_close":2024.5,"volume":289700}
]
```

上は説明用の抜粋（**実際に実行するファイルには連続する正しい21取引日分の全行が必要**）。

```sh
export DATABASE_URL='<private secret>'
python joint_pattern_forecast.py --symbol 7846 --as-of 2026-10-09 \
  --bars-json private-current-21.json --out private-pilot-forecast.json
```

### すでにパターンと基準価格が確定している場合

```sh
python joint_pattern_forecast.py --symbol 7846 --as-of 2026-10-09 \
  --patterns HIGH20,SMA_BULL --base-price 2173.5 \
  --out private-pilot-forecast.json
```

1～30営業日ごとの `up_fraction_pct`、`down_fraction_pct`、観測件数、`historical_median_return_pct`、`scenario_median_yen`、上下25/75分位のシナリオ価格などをJSONへ保存。標準ログは1・2・3・5・10・20・30日だけを要約表示。未来の株価ではなく**過去の類似事例を現在価格に縮尺変換したシナリオ**。銘柄以外の入力もプライベートデータとして扱う。

## 未解決

- 21営業日の**最新OHLCVを自動取得する仕組み**はまだ完成していない。J-Quantsの無料枠はデータに遅れがあり、2026年10月9日の株価を2026年7月17日のNeon価格で代用してはならない。
- 全銘柄の全JPX上場廃止・指定履歴と株式分割の時点別調整。上場廃止銘柄の未来価格が欠損した場合、分母から落ちる生存者バイアスがある。
- 統計学的な予測確率の較正、相場環境、セクター/時価総額の分離、現金約定・逆指値・実売買コストのモデル化。
- 学習済み期間とは別の本物の将来期間に対する事前登録したアウトオブサンプル精度の検証。過去の中央値を将来の期待価格と断定しない。
