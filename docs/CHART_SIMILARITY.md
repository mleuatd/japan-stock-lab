# チャート画像からの類似形状検索と、その後の騰落統計

この機能の目的は**購入の断定ではなく、貼り付けたチャートに似た歴史的事例を探し、その後の実測騰落の分布を見せる**ことです。

## 入力

1. `docs/index.html` で、利用許諾のある私用日足CSV.gzをそのブラウザーに取り込む。
2. `docs/similarity.html` から検索する。スクリーンショットを読み込み、左→右へチャートのラインをタップして形をなぞる。ローソク足しかない画像は元の終値の線を正確には復元できないため、結果は手入力に依存する。
3. スクリーンショットの代わりに、銘柄コード（例 `7203`）から保存済み日足の直近20営業日を自動で参照できる。価格配列を直接貼り付けることも可能。
4. 比較期間10/20/30/60日、採用する類似例10/30/50/100を指定する。

**画像自動OCRや機械学習によるキャンドルの自動読み取りは未実装**。画像の単純な線を人が指でなぞって参照パターンにする暫定UIである。画像をこのチャットに添付したときは、ChatGPTが形状の特徴を確認し、必要に応じて検索するための数値列を作れる。

## 類似条件・未来データの排除

- 値動きの縦軸の倍率や価格水準に依存しない**Z正規化曲線のRMSE距離**。低いほど似ている。指標は恣意的な「類似率99%」ではなく距離を表示。
- 一つの候補は形状を判定するN営業日と、続く20営業日の調整後終値が**欠落せずに実際に観測されている**ことを要求する。前日欠損を「営業日連続」と誤解しない。
- 未来側の実際の価格は、その候補が**類似しているかを判定する処理には使わない**。照合後の騰落実績だけを計算する。
- 同じ証券コードの大量の重複した窓を別々の独立事例としてカウントしないよう、形状N日＋未来20日が重なるケースは近い方の代表例にまとめる。
- 採用事例を**距離が近い順**に最大K個。上昇した事例だけを選択することはしない。
- 各事例について5/10/20営業日後の上昇・下落・横ばいと騰落率を提示し、全体では上昇割合・件数・中央値・95% Wilson参考区間を示す。
- 上昇割合は **経験的な類似事例の比率**。将来の上昇確率としての較正・保証はない。母集団の売買停止/上場廃止や相場環境の違いにより大きく偏ることがある。
- 画像からの曲線は絶対価格やパーセンテージを示さない。株式分割・配当・上場廃止についても完全な企業行動照合は未完了。元の日足の鮮度は最新の株価を保証しない。

## 実装

- `chart_similarity.py`: Python標準ライブラリのみ。全日足（Private Neon/非公開CSV）を入力して類似例と未来20営業日を計算。公表ログは集計のみ、個別銘柄の結果を含むJSONは非公開環境内だけに保存。
- `docs/similarity.html`: 画像トレース、入力数列、銘柄コードの3方式。IndexedDB内の私用CSVを端末上だけで処理し、上昇割合・一致例のローソクでない価格曲線を表示。画像を外部送信しない。
- `tests/test_chart_similarity.py`: スケール不変、類似事例の重複排除、参照時点より後の情報への不依存、未来20日未観測事例の除外、欠損市場日の扱い。

### 非公開Python実行例

```sh
python chart_similarity.py --curve-json private-reference-curve.json --from-neon --lookback 20 --top 30 --out private-chart-neighbors.json
```

`private-reference-curve.json` は左から右の価格高さを3点以上含むJSON配列。`DATABASE_URL` はSecretsから渡し、公開GitHubリポジトリには置かない。

### 画面での出力例（架空の数値）

`20営業日後：上昇21件 / 30件（70%）、下落8件、横ばい1件。95%参考区間：... / 中央騰落...。`

下に「銘柄、パターンの終了日、距離、5・10・20営業日後の実際の騰落」を1件ずつ並べ、終了日までの形と終了後の値動きをグラフで区切って表示。

**判定**: 新機能のテスト通過は実市場の予測能力を証明しない。後続タスクとして、期間外検証、企業行動ソース検証、複数の市場状況とベースレート比較、実運用可能な入力日の価格鮮度検証が必要。すべて実注文禁止。
